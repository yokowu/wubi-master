# ✍️ 五笔达人 (Wubi Master)

**五笔达人 (Wubi Master)** 是一款专为五笔字型学习者设计的现代化、极简主义刻意练习网站。

不同于市面上简陋的打字测试工具，本项目从五笔学习者的**核心痛点**出发，结合自适应特训算法与动态笔画拆分，帮助练习者快速跨越“拼音依赖”与“拆字断联”的瓶颈，建立直觉般的字根肌肉记忆。

---

## 🎯 痛点与解决方案

在学习五笔的过程中，你是否也遇到过以下痛点？**五笔达人**为此提供了针对性的解决方案：

### 1. 😖 痛点：拼音肌肉记忆顽固，遇到生疏字频繁卡顿
* **现状**：初学者打字时脑中会不自觉地浮现拼音，一旦字根记不准就会卡住，不得不切换回拼音输入，导致建立肌肉记忆的过程极慢。
* **解法：自适应薄弱键位特训 (Adaptive Practice)**
  * 系统采用**五区五画理论**，将键盘分区精准映射到汉字的五种基本笔画（横、竖、撇、捺、折）。
  * 实时捕获您每次击键错误的键位，自动计算五个笔画区的错字频次，生成直观的薄弱度柱状图。
  * 开启 **【薄弱区强化模式】** 后，系统会自动提取该区域的历史错字，动态混合同笔画高频字，生成 30 字的专项练习序列，进行精准爆破。

### 2. 🤯 痛点：拆字规则抽象难记，传统拆解字根显示乱码
* **现状**：网上查字根要么是静态图片，要么由于使用了私有区（PUA）Unicode 字符，导致字根符号在浏览器里渲染为方块、问号或乱码。
* **解法：动态笔画拆解 + 专用字根字体集成**
  * 集成了 **HanziWriter 动态笔画拆分**，支持笔画分步高亮，配合深邃靛蓝（`#1a365d`）高亮色，清晰还原每一个字的物理拆解顺序。
  * 本地托管了 **86/98版五笔专用字根字体**，在 `style.css` 中配置专属 `@font-face` 规则，完美渲染全部 PUA 字符，彻底告别乱码。

### 3. 📉 痛点：输入字数少于四码时，识别码（末笔字型码）容易遗忘
* **现状**：诸如“套”（`ddu`）这类字，笔画拆解只有 2 组，但编码有 3 码（最后一码为识别码）。传统的拆分只显示笔画，识别码按键及其字根符号很容易被学习者忽略。
* **解法：防丢识别码卡片 (Recognition Code Preservation)**
  * 当五笔编码长度大于笔画拆分段数时，系统会在笔画拆解网格的末尾**自动追加识别码卡片**。
  * 该卡片以纯浅灰色渲染完整的汉字背景，并明确标注识别码按键（如 `U`）及对应的识别码字根符号（如 ``），让拆字逻辑严丝合缝。

### 4. 😑 痛点：单字框打字枯燥且破坏节奏，无法形成流式击键
* **现状**：很多软件采用“打完一个字跳下一个字”的模式，视线无法提前预瞄，根本无法模拟现实中的流畅录入。
* **解法：全字词流式排版 (Flowing Text Layout)**
  * 采用开阔大气的流式文本排版。视线可自然预瞄后方的文字。
  * 已输入字半透明淡出，输入中字高亮环绕并带有细微缩放动效，未输入字保持清晰。带给您行云流水般的流畅节奏感。

### 5. 💔 痛点：学习反馈冰冷，遇到挫折期容易放弃
* **现状**：机械的打字速度和准确率数据，让人看着头疼，缺乏长线学习的动力。
* **解法：多维 SVG 折线图 + 陪伴式有温度的诊断报告**
  * 内置高级多线并行 SVG 趋势图，可交互筛选不同练习模式的成绩走势。
  * 练习结束后弹出诊断报告，针对打字速度（WPM）、准确率、退格率和卡顿率，给出富有同理心且幽默风趣的个性化分析与记忆建议。
  * 错词自动计入 Ledger，支持一键导出为标准的 **Anki** 格式文件，便于进行卡片式复习。

## 🏗️ 现代化全栈架构

项目已完成全栈重构，由单机前端应用升级为现代化的前后端分离架构：

```text
wubi-master/                     # 根目录
├── docker-compose.yml           # 容器一键编排配置
├── frontend/                    # 前端子目录 (Vite + Vanilla JS + CSS3 + Nginx)
│   ├── src/                     # 前端源代码 (main.js, style.css)
│   ├── public/                  # 静态资源 (托管专用字根字体 wubi_86_radicals.ttf 等)
│   ├── Dockerfile               # 前端 Nginx 镜像构建
│   └── nginx.conf               # 反向代理配置 (处理前端路由及 API 转发)
└── backend/                     # 后端子目录 (Rust + Axum + SQLx + PostgreSQL)
    ├── src/                     # Rust 源代码 (使用 Axum 0.7+ 构建)
    ├── Cargo.toml               # Cargo 依赖定义
    ├── Dockerfile               # Rust 编译与多阶段轻量化运行镜像
    └── wubi_seed_data.json      # 3,500 常用字五笔拆分数据源
```

## 🚀 快速开始 (Docker Compose 一键部署)

我们推荐使用 Docker Compose 进行本地运行，它会自动配置 Nginx 代理、Rust API 和 PostgreSQL 18 数据库，并自动完成 3,500 常用字的数据初始化。

### 1. 启动服务
在项目根目录下执行：
```bash
docker compose up -d --build
```

### 2. 访问应用
* 前端地址：[http://localhost:8088](http://localhost:8088) (直接在浏览器中打开即可开始练习)
* API 接口调试地址：[http://localhost:5000/api/wubi/套](http://localhost:5000/api/wubi/%E5%A5%97)

### 3. 关闭服务
```bash
docker compose down
```

## 🛠️ 技术细节

* **前端构建**：Vite 8 + CSS3 原生变量（双色温护眼主题：极简灰黑 / 仿宣纸暖黄书页）。
* **后端 API**：Rust 异步 Web 框架 Axum 0.7 + 异步数据库 SQLx。
* **数据持久化**：PostgreSQL 18，容器启动时自动检测表结构并完成数据种子导入。
* **字形渲染**：结合 [HanziWriter](https://hanziwriter.org/) 的 SVG 路径进行动态笔画拆解。
