# 五笔达人 (Wubi Master)

**五笔达人 (Wubi Master)** 是一款专为五笔字型（86版）学习者设计的现代化、极简主义打字刻意练习网站。

本项目旨在帮助学习者摆脱对拼音输入的依赖，跳出逐字击键的视觉断联感，建立直觉性的字根肌肉记忆。

---

## ✨ 核心特色

### 1. 📖 全字词段落流式输入 (Flowing Text Paragraph)
* **消除断联感**：废除传统的“单字滚动”模式，所有练习字符以排版开阔的流式文本（Flowing Text）展示在屏幕中央，便于视线提前预瞄。
* **状态动态指示**：
  * **已完成字**：半透明淡灰色，附带删除线，自然淡出视野。
  * **输入中字**：粗体、温润灰色背景及细木炭色边框环绕，伴随焦点微缩放动效。
  * **未完成字**：正常显示，便于流畅连贯的持续敲击。

### 2. 🎯 纯正标准的一级简码专项
* **精简专注**：去除了混杂在练习库中的“键名字”（如“金”等四码键名），完全收录标准的 **25个一级简码汉字**（从 `A` 到 `Y`），专注练习核心单键字。

### 3. 🍃 极简线稿风美学 (Airy Line-Art)
* **柔和炭黑细线条**：界面采用 `1px` 极细炭灰色（`#333333`）边框，弱化视觉压迫。
* **高留白设计**：大面积优雅留白与呼吸感间距，界面清爽，让您长时间练习不易疲劳。
* **宣纸护眼模式**：支持一键切换“极简白”与“仿宣纸暖黄书页”背景，更贴合阅读体验。

### 4. 🗃️ 错词 ledger 与内置 Anki 导出
* 实时记录输入错误的汉字，支持一键复制到剪贴板或导出为标准 `.txt` (TSV) 文件，方便直接导入 **Anki** 进行卡片式复习。

### 5. 🔄 丝滑重置交互
* 导航栏右侧集成重置按钮，鼠标悬停时会伴随 `-180deg` 顺滑旋转的微动效，一键重置当前练习轮次与各项打字数据。

---

## 🛠️ 技术栈

* **构建工具**：Vite
* **核心语言**：Vanilla JavaScript, HTML5
* **样式处理**：CSS3 (原生 CSS 变量设计，多主题无缝切换)
* **码表数据**：Rime 86 极点五笔标准词库

---

## 🚀 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```
启动后在浏览器中打开：[http://127.0.0.1:8000](http://127.0.0.1:8000)

### 3. 生产环境打包
```bash
npm run build
```
打包后生成的静态资源文件将存放在 `dist` 目录中。
