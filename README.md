# 五笔达人 (Wubi Master)

**五笔达人 (Wubi Master)** 是一款专为五笔字型（86版）学习者设计的现代化、极简主义打字刻意练习网站。

本项目旨在帮助学习者摆脱对拼音输入的依赖，跳出逐字击键的视觉断联感，通过系统科学的自适应强化训练建立起直觉性的字根肌肉记忆。

---

## ✨ 核心特色

### 1. 📖 全字词段落流式输入 (Flowing Text Paragraph)
* **消除断联感**：废除传统的“单字滚动”模式，所有练习字符以排版开阔的流式文本（Flowing Text）展示在屏幕中央，便于视线提前预瞄。
* **状态动态指示**：
  * **已完成字**：半透明淡灰色，附带删除线，自然淡出视野。
  * **输入中字**：粗体、温润灰色背景及细木炭色边框环绕，伴随焦点微缩放动效。
  * **未完成字**：正常显示，便于流畅连贯的持续敲击。

### 2. 🎯 纯正标准的一级简码专项
* **精简专注**：去除了混杂在练习库中的“键名字”（如“金”等四码键名），完全收录标准的 **25个一级简码汉字**（从 `A` 到 `Y`），专注练习核心单键字。

### 3. 📊 笔画键区薄弱度分析与自适应特训
* **五区五画理论映射**：将键盘的 5 个物理分区与汉字的 5 种基本笔画（横 `G-A`、竖 `H-M`、撇 `T-Q`、捺 `Y-P`、折 `N-X`）进行一对一精准映射。
* **错误频率追踪**：系统自动捕获每一次按错键时的目标键位，归纳统计五个笔画区的错字频次，并在控制台以动态比例柱状图实时展示您的薄弱区域。
* **自适应强化特训**：一键开启【薄弱区强化】模式，系统会自动定位您当前最薄弱的笔画区，动态混合“历史错字”与“同笔画高频字”，生成 30 字的定制强化训练序列，进行精准突破。

### 4. 📈 多维度 SVG 趋势折线图 & 训练日志
* **多线并行图表**：内置基于纯 SVG 绘制的高级图表，折线图区分练习模式（以不同颜色、不同几何标记如圆形、方形、多边形等区分），支持 legend 交互式筛选，鼠标悬停可展示包含 WPM、准确率、时间和错字数在内的多维度 Tooltip。
* **本地存储与导出**：本地存储自动记录最近 500 次的打字数据；支持一键将历史日志以 UTF-8 BOM 编码格式导出为标准 CSV 表格，方便您进行个人数据分析。

### 5. 🌸 高情绪价值的诊断报告
* **有温度的文字交互**：打字结束后自动弹出详细的诊断报告。针对您的打字速度（WPM）、准确率、退格率以及卡顿率，系统会以极富同理心和人情味的幽默评语给予反馈，在肯定您进步的同时，给出针对性的肌肉记忆训练建议。

### 6. 🗃️ 错词 ledger 与内置 Anki 导出
* 实时记录输入错误的汉字，支持一键复制到剪贴板或导出为标准 `.txt` (TSV) 文件，方便直接导入 **Anki** 进行卡片式复习。

### 7. 🍃 极简线稿风美学 (Airy Line-Art)
* **柔和炭黑细线条**：界面采用 `1px` 极细炭灰色（`#333333`）边框，弱化视觉压迫。
* **高留白设计**：大面积优雅留白与呼吸感间距，界面清爽，让您长时间练习不易疲劳。
* **双色温护眼模式**：支持一键切换“极简灰黑”与“仿宣纸暖黄书页”背景，更贴合您的阅读及打字专注体验。

---

## 🛠️ 技术栈

* **构建工具**：Vite
* **核心语言**：Vanilla JavaScript, HTML5
* **样式处理**：CSS3 (原生 CSS 变量设计，多主题无缝切换)
* **码表数据**：Rime 86 极点五笔标准词库（已引入现代汉语 3500 常用字白名单进行过滤，100% 纯正无杂质中文练习库）

## 🚀 快速开始

### 1. 本地运行

#### 安装依赖
```bash
npm install
```

#### 启动开发服务器
```bash
npm run dev
```
启动后在浏览器中打开：[http://127.0.0.1:8000](http://127.0.0.1:8000)

#### 生产环境打包
```bash
npm run build
```
打包后生成的静态资源文件将存放在 `dist` 目录中。

---

### 2. Docker 部署

本项目支持通过 Docker 容器化方式进行本地快速构建和部署。

#### 启动服务
在项目根目录下执行以下命令：
```bash
docker-compose up -d
```
服务启动后，可以通过浏览器访问：[http://localhost:8000](http://localhost:8000)

#### 停止服务
```bash
docker-compose down
```
